# SCENTORA – Perfume Inventory Management Dashboard

SCENTORA is a perfume inventory management dashboard designed to help administrators manage and monitor perfume products.

## Features

- Dashboard overview and inventory statistics
- View all available perfumes
- Search perfumes by name, brand, and category
- View individual perfume details
- Responsive interface built with Tailwind CSS
- Reusable data-fetching hooks

## Technologies

- React
- Vite
- Tailwind CSS
- React Router
- JSON Server

## Installation

Install dependencies:

npm install

## Run the application

npm run dev

## Start the database server

npm run server

The database runs at http://localhost:3000.
